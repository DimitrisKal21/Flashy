# Flashy 🃏

**Εφαρμογή flash cards για εκμάθηση λεξιλογίου Ελληνικών και Αγγλικών, γραμμένη σε Python με tkinter.**

Διαλέγεις γλώσσα, βλέπεις μια λέξη και, αν δεν θυμάσαι τη μετάφρασή της, η κάρτα γυρίζει και στη δείχνει. Οι λέξεις που δεν ξέρεις επιστρέφουν στο τέλος της λίστας, ενώ οι λέξεις που έμαθες φεύγουν οριστικά. Η πρόοδος αποθηκεύεται αυτόματα και συνεχίζεις από εκεί που σταμάτησες.

## Χαρακτηριστικά

- **Επιλογή γλώσσας με σημαίες** στην αρχική οθόνη. Μπορείς να μάθεις Αγγλικά (η κάρτα δείχνει αγγλική λέξη και μετά την ελληνική μετάφραση) ή Ελληνικά (το αντίστροφο).
- **Κάρτα με δύο όψεις:** μετά το γύρισμα η αρχική λέξη μένει στην οθόνη και από κάτω εμφανίζεται η μετάφραση, με μικρές σημαίες δίπλα σε κάθε λέξη.
- **Αυτόματο γύρισμα** μετά από 3 δευτερόλεπτα, ή άμεσο γύρισμα με το κουμπί X.
- **Ουρά επανάληψης:** οι λέξεις που δεν ξέρεις πηγαίνουν στο τέλος της λίστας και ξαναβγαίνουν αργότερα.
- **Αυτόματη αποθήκευση προόδου**, ξεχωριστά για κάθε γλώσσα.
- **Reset** όταν μάθεις όλες τις λέξεις, με ερώτηση Ναι/Όχι.

## Εγκατάσταση

**Απαιτήσεις:** Python 3 και οι βιβλιοθήκες `pandas` και `pillow`. Η tkinter περιλαμβάνεται στην Python.

1. Κατέβασε το project:

   ```
   git clone https://github.com/DimitrisKal21/Flashy.git
   cd Flashy
   ```

2. (Προαιρετικά, αλλά προτείνεται) Φτιάξε εικονικό περιβάλλον:

   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```

   Σε macOS ή Linux η δεύτερη εντολή είναι `source .venv/bin/activate`.

3. Εγκατάστησε τις βιβλιοθήκες:

   ```
   pip install -r requirements.txt
   ```

4. Τρέξε την εφαρμογή:

   ```
   python main.py
   ```

## Χρήση

1. **Διάλεξε γλώσσα:** πάτα την ελληνική σημαία για να μάθεις ελληνικά ή τη βρετανική για να μάθεις αγγλικά.
2. **Δες τη λέξη:** έχεις 3 δευτερόλεπτα να σκεφτείς τη μετάφρασή της.
3. **Η κάρτα γυρίζει:** εμφανίζεται η μετάφραση κάτω από τη λέξη.
4. **Πες στο πρόγραμμα αν την ήξερες:** πάτα ✓ αν την ήξερες ή X/Next αν δεν την ήξερες.
5. **Συνέχισε μέχρι να τελειώσουν οι λέξεις.** Τότε εμφανίζεται ερώτηση αν θες να ξεκινήσεις από την αρχή (Ναι) ή να κλείσει το πρόγραμμα (Όχι).

Μπορείς να κλείσεις την εφαρμογή όποτε θες. Την επόμενη φορά που θα διαλέξεις την ίδια γλώσσα, θα συνεχίσεις από εκεί που σταμάτησες.

## Τα κουμπιά

| Κατάσταση της κάρτας | Κουμπί | Τι συμβαίνει |
|---|---|---|
| Δεν έχει γυρίσει | **X** | Η κάρτα γυρίζει αμέσως, χωρίς να περιμένει τα 3 δευτερόλεπτα. |
| Δεν έχει γυρίσει | **✓** | Η λέξη αφαιρείται οριστικά και εμφανίζεται η επόμενη. |
| Δεν έχει γυρίσει | **Next** | Ανενεργό (γκρι). |
| Έχει γυρίσει | **X** | Η λέξη πηγαίνει στο τέλος της λίστας και εμφανίζεται η επόμενη. |
| Έχει γυρίσει | **Next** | Ίδιο με το X: η λέξη πηγαίνει στο τέλος και εμφανίζεται η επόμενη. |
| Έχει γυρίσει | **✓** | Η λέξη αφαιρείται οριστικά και εμφανίζεται η επόμενη. |

## Οι λέξεις

Οι λέξεις βρίσκονται στο `data/greek_words.csv`, μία ανά γραμμή:

```
Greek,English
Μέρος,Part
Ιστορία,History
```

- Η πρώτη γραμμή πρέπει να είναι ακριβώς `Greek,English`, γιατί ο κώδικας διαβάζει τις στήλες με αυτά τα ονόματα.
- Το ίδιο αρχείο χρησιμοποιείται και για τις δύο γλώσσες.
- Για να προσθέσεις δικές σου λέξεις, γράψε νέες γραμμές με την ίδια μορφή και σβήσε τα αρχεία προόδου (βλ. παρακάτω), ώστε να φορτωθεί η νέα λίστα.

**Αρχεία προόδου.** Η εφαρμογή τα δημιουργεί μόνη της στον φάκελο `data`:

| Αρχείο | Πότε χρησιμοποιείται |
|---|---|
| `words_to_learn_english.csv` | Όταν μαθαίνεις Αγγλικά |
| `words_to_learn_greek.csv` | Όταν μαθαίνεις Ελληνικά |

Περιέχουν μόνο τις λέξεις που δεν έχεις μάθει ακόμα, με τη σειρά που θα εμφανιστούν. Για να ξεκινήσεις μια γλώσσα από την αρχή, σβήσε το αντίστοιχο αρχείο. Τα αρχεία αυτά δεν ανεβαίνουν στο GitHub (είναι στο `.gitignore`).

## Πώς δουλεύει

**Η λίστα είναι ουρά.** Η κάρτα που βλέπεις είναι πάντα το πρώτο στοιχείο της λίστας `to_learn`. Με το ✓ η λέξη αφαιρείται (`pop(0)`). Όταν δεν την ξέρεις, μετακινείται στο τέλος (`to_learn.append(to_learn.pop(0))`). Παράδειγμα: από `[A, B, C]`, αν δεν ξέρεις το A, η λίστα γίνεται `[B, C, A]`. Οι λέξεις ανακατεύονται μία φορά στην αρχή κάθε γύρου.

**Το γύρισμα γίνεται με χρονόμετρο.** Κάθε νέα κάρτα ξεκινάει `window.after(3000, flip_card)`. Πριν από κάθε αλλαγή κάρτας (και στο X), το παλιό χρονόμετρο ακυρώνεται με `window.after_cancel(flip_timer)`, ώστε να μη γυρίσει μια νέα κάρτα πολύ νωρίς.

**Η εφαρμογή θυμάται την κατάσταση της κάρτας.** Η μεταβλητή `is_flipped` κάνει το X να δουλεύει σε δύο βήματα: πρώτα γυρίζει την κάρτα και μετά περνάει στην επόμενη.

**Η πρόοδος σώζεται σε ξεχωριστό αρχείο ανά γλώσσα.** Μετά από κάθε ✓ ή μετακίνηση στο τέλος, η λίστα γράφεται στο αρχείο προόδου με pandas.

**Οι σημαίες φορτώνονται με Pillow** και αλλάζουν μέγεθος αυτόματα, οπότε δουλεύουν όποιο μέγεθος κι αν έχουν τα αρχεία.

Οι βασικές συναρτήσεις του `main.py`:

| Συνάρτηση | Ρόλος |
|---|---|
| `start_game(language)` | Ορίζει γλώσσα και αρχείο προόδου, φορτώνει τις λέξεις και χτίζει την κάρτα |
| `load_words()` / `reset_words()` / `save_progress()` | Φόρτωση, επαναφορά και αποθήκευση των λέξεων |
| `next_card()` | Δείχνει την επόμενη κάρτα και ξεκινάει το χρονόμετρο |
| `flip_card()` | Γυρίζει την κάρτα και δείχνει τη μετάφραση |
| `is_known()` | Κουμπί ✓ |
| `is_unknown()` | Κουμπί X |
| `move_to_end()` | Στέλνει τη λέξη στο τέλος της λίστας (Next και X σε γυρισμένη κάρτα) |

| Τι θες να αλλάξεις | Πού |

## Συχνά προβλήματα

| Τι βλέπεις | Αιτία | Λύση |
|---|---|---|
| `ModuleNotFoundError: No module named 'PIL'` ή `'pandas'` | Δεν έχουν εγκατασταθεί οι βιβλιοθήκες | `pip install -r requirements.txt` |
| `KeyError: 'Greek'` ή `KeyError: 'English'` | Οι επικεφαλίδες του CSV δεν είναι ακριβώς `Greek,English` | Διόρθωσε την πρώτη γραμμή του `greek_words.csv` |
| `FileNotFoundError` για αρχείο `.png` | Λείπει εικόνα ή το πρόγραμμα τρέχει από λάθος φάκελο | Τρέξε `python main.py` μέσα από τον φάκελο του project |
| Η σημαία είναι τεράστια ή δεν φορτώνει | Το αρχείο δεν είναι έγκυρη εικόνα | Αποθήκευσέ το ξανά ως PNG |
| Εμφανίζονται παλιές λέξεις | Υπάρχει παλιό αρχείο προόδου | Σβήσε τα `words_to_learn_*.csv` από τον φάκελο `data` |
